## Dependency Graph

### Direction

- **app/** → **layouts/** → **components/** → **contexts/** → **lib/** → **data/** (Unidirectional, no cycles)
- **Contentlayer2** (build-time) → **data/\*.mdx** → **contentlayer/generated** → **app/** (static imports)
- **components/** ('use client') → **contexts/** (LanguageProvider, ThemeProviders, SearchProvider)
- **lib/PreferencesService** → **localStorage** (user preferences: theme, language, cert grouping)
- **lib/generateSearchIndex** (build-time) → **data/blog/** + **data/projects/** → **public/search.json**
- **scripts/postbuild.mjs** (after next build) → **out/feed.xml** (RSS feed)

### Boundaries

- **Server vs. Client**: App routes are server-rendered; components marked `'use client'` are client-rendered. Clear boundary enforced by Next.js.
- **Build-time vs. Runtime**: Contentlayer, tag generation, search index: build-time artifacts. PreferencesService, LanguageContext: runtime client-side.
- **Static Export**: No API routes; all data baked into static output at `/out/`. Deployment model is immutable HTML/JSON.
- **Observed cycles**: None detected. Dependency graph is acyclic (DAG).

## Summary

**Light Stimulus** is a static-export Next.js portfolio and blog site showcasing AR/XR/AI projects. Built with **Contentlayer** for MDX content management, **client-side i18n** (LanguageContext + localStorage preferences), and **next-themes** for dark mode support.

**Key characteristics**:

- Zero backend APIs; all data is static HTML/JSON baked at build time.
- Clear server/client boundary enforced via `'use client'` markers.
- Comprehensive test suite: 240+ test files using Vitest + React Testing Library.
- No observed dependency cycles; unidirectional dependency graph (DAG).
- Deployed as immutable static output to Netlify via GitHub CI.
